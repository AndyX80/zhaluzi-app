# Десктопная версия «Жалюзи-СПб» (каркас)

Статичное приложение без сборки: `index.html`, `app.css`, `js/*.js`. Открывается на GitHub Pages по адресу `/desktop/`.
Данные демонстрационные (`js/data.js`), реальных клиентов, цен и закупа в репозитории нет.

## Архитектура
- `js/core.js`: состояние (`App.S`, хранится в localStorage), вкладки, переключатель режимов (Alt+1…6), глобальный поиск, события, тема.
- Модуль = файл `js/m-*.js`, регистрируется `App.module(id, { render(), card?(), after?() })`. Действия кнопок: `App.act[имя]` (атрибут `data-a`), поля: `App.fld[имя]` (атрибут `data-c`).
- Центральный объект — **Заказ** (`m-orders.js`): воронка, вкладки (Общая, Замер, Изделия, Финансы, Документы, Поставщик и доставка, История), итоги.
- Первая вкладка = текущий раздел, остальные = открытые заказы и клиенты.
- Новый раздел: добавить пункт в `NAV` (`core.js`), файл `m-<id>.js`, подключить в `index.html`.

## Этапы
0. Каркас (этот).
1. Перенос телефонной версии: настоящий расчёт, замерник, КП, договор, заказы, общая база.
2. Клиенты, календарь Google, импорт «Учёт заказов» с начала 2026.
3. Деньги, аналитика, Эльба и Диадок.
4. Остальная продукция.
